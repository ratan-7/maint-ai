# General Maintenance Guide

## Safety Before Inspection

### Required Actions

1. Stop the equipment before physical inspection.
2. Follow the site's lockout/tagout procedure.
3. Verify that moving components have stopped.
4. Allow hot components to cool when required.
5. Use appropriate personal protective equipment.

### Evidence

Physical inspection should only be performed after the equipment has been placed in a safe state according to applicable site procedures.

---

## Vibration Inspection

### Inspection Procedure

1. Record the current vibration reading.
2. Compare the reading with the applicable equipment limit.
3. Check for unusual noise.
4. Inspect mounting points.
5. Check shaft and coupling alignment.
6. Inspect bearings.
7. Check for mechanical looseness.

### Evidence

Vibration readings should be interpreted together with operating conditions and physical inspection findings.

---

## Temperature Inspection

### Inspection Procedure

1. Record the current temperature.
2. Verify that the sensor reading is valid.
3. Compare the reading with the applicable equipment limit.
4. Check lubrication.
5. Inspect cooling arrangements.
6. Check for abnormal load conditions.

### Evidence

Temperature readings should be verified before making maintenance decisions, particularly when sensor readings are missing or conflicting.

---

## Conflicting Sensor Readings

### Procedure

If two sensors provide significantly different readings:

1. Record both readings.
2. Do not assume one reading is correct.
3. Check sensor condition and calibration.
4. Verify the reading using an appropriate independent measurement method.
5. Mark the sensor data as uncertain until verification is completed.

### Evidence

Conflicting measurements should be verified before relying on them for maintenance decisions.

---

## Maintenance Priority

### General Guidance

- LOW: No immediate abnormal condition identified.
- MEDIUM: Abnormal condition requires inspection but no immediate critical indication.
- HIGH: Significant abnormal condition requires timely technician attention.
- CRITICAL: A potentially unsafe or severe condition requires immediate attention according to site procedures.

### Evidence

Priority should consider sensor results, equipment condition, operating events, safety implications, and technician verification.
